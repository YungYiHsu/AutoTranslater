# Codex 圖片提取

電子書的「Codex 提取」為獨立分頁，與 YomiToku 分開，不提供雙引擎比較。
沿用網文的 CodexClient、ChatGPT 登入、模型與推理設定、900 秒回合等待上限。
同一作品的圖片提取沿用專用 thread，識別保存在作品 codex_extraction_thread.json；
不同作品分開，不續接網文、不改用 API Key、不自動重試。重啟後繼續沿用。
舊版分散對話不自動合併；升級後首次提取建立作品專用串。切換模型或 Prompt 仍續接同串，
每次帶入最新規則並要求只輸出本次圖片。清空 OCR 工作備份不會清除對話識別或遠端歷史。
續接失敗不另建新串；帳號不符、上次回合進行中或狀態不明時停止送出。
codex_extraction_thread.lock 防止多個程式同時提取；異常關閉留下鎖時須確認無工作後手動移除。
提取按鈕統一為「提取內文」。主 GUI「Prompt 模板」中的「電子書內文提取」
於下次提取讀取，與固定純文字輸出及安全要求合併後保存於 prompt.txt。
兩種模式各自恢復最近有效備份，損壞紀錄往前尋找，不自動重新辨識。
Codex 用量區可手動查詢額度、查看作品提取歷史；請求前後快照與耗時記錄在
作品 codex_usage.jsonl，不隨清空 OCR 備份刪除。失敗及取消也記錄。
額度差是帳號觀測值，可能包含其他任務或回報延遲，不能視為圖片的精確費用。

全螢幕截圖保留原始尺寸；本機預覽只顯示所選半頁，但送出的 localImage
是完整原圖，沒有裁切或影像增強。首次送出確認保存在 runtime/ebook/。
內建提取指令排除振假名、頁首、頁碼與插圖文字，保留正文、章標、圖說、
註腳、符號和原字形；無法辨讀使用 □。回傳整張圖片的連續純文字，
不要求左右頁或逐欄 JSON；接合跨欄句子，保留段落換行，不進行語意改寫。

資料保存於作品 ocr/<時間>-codex-<ID>/：
- original.png：完整截圖。
- prompt.txt、request.json：本次指令、模型、回合識別、狀態和耗時。
- raw-response.txt、raw-turn.json：原始回覆，格式解析失敗時仍保留。
- codex.json：最新成功提取、校訂文字及匯出頁碼。

重新提取失敗不覆蓋已成功的校訂；最新執行診斷取代前次診斷，不提供歷史版本選單。
重新選取作品或重啟後載入最新 Codex 本機紀錄；不自動重新發送。
取消透過 turn/interrupt，在工作執行緒處理，非從 Tk 執行緒同時讀寫 RPC。
UI 關閉或作品切換須等待工作結束；背景執行不操作 Tk。

匯出內文沿用頁碼、章節預填與 chapters.json 排序。
chapters.json 使用 pages：OCR 同頁各欄合併為單頁紀錄；Codex 整張圖存為
start_page/end_page 頁碼範圍與 text，不猜測原文的實際分頁位置。
同一作品內每個頁碼只能歸屬一個章節，跨章節範圍重疊會拒絕匯出並指出衝突章節。
「匯出選取文字」也遵守此規則，不能把同頁不同段落分別匯入不同章節。
既有跨章重疊資料不自動搬移或刪除；與其他章節衝突的後續匯出仍會被拒絕。
若目標章節已包含該頁，確認畫面明確說明：取代該章該頁全部舊文字，
不是跨引擎猜測行號對齊。因此同頁同章的多段文字應一起選取後匯出。
其他頁與其他章不受影響。覆蓋必須涵蓋完整舊範圍並確認：既有 Codex 10–11，
可用完整 OCR 10、11 取代，單獨 10 或 11 不可；部分行或選取文字不能取代多頁紀錄。
同頁同章匯出會取代整頁，不再按欄追加。舊 rows 仍可讀，首次成功匯出時轉為 pages，
轉換前保存 chapters.legacy-<SHA256>.json 備份。章節 TXT 檔名不變。
圖片只在正式匯出保存到 images/；章節寫入失敗會移除該次新增圖片。
清空 OCR 會移除兩種引擎的工作備份，不影響 images/、originals/、translations/、chapters.json。

安全：延用既有禁止 shell、apps、外掛、MCP、網頁搜尋的設定，唯讀 sandbox、
approvalPolicy=never，工作目錄為本次紀錄，不傳入整個作品。
協定依據：https://learn.chatgpt.com/docs/app-server
測試使用合成圖片與模擬 RPC，不自動傳送私人樣本或耗用模型額度。
