# v0.4.0 更新說明

發布日期：2026-09-26。

## 新增與調整

- EPUB 匯出不再自動開啟網頁；可另選手動上傳或自動上傳至 Kindle。
- 自動上傳使用全新的 Chrome／Edge 工作階段，每次自行登入，送出前置頂確認，不保留瀏覽器登入狀態。
- 新增 Gmail Email 寄送 EPUB 至 Kindle、認證測試、重複寄送提醒與寄送結果紀錄。密碼只存 Windows 認證管理員，不自動重送郵件。
- Codex 既有作品建立新對話前，先送作品名稱與摘要作為背景；新作品第一次翻譯名稱／摘要不重複初始化。
- Codex 額度區可摺疊；總消耗採首尾快照差值，每章平均以實際有請求的章節數計算，依 UTC 快照時間判斷重置。移除 Token 消耗統計，保留上下文容量估計。
- 移除舊單一 JSON checkpoint 的遷移、舊章節檔名辨識及未使用的舊工具；現行 checkpoint 合併為單一模組。

## 升級注意事項

1. 先關閉程式，再替換 `AutoTranslater.exe` 與整個 `_internal`。
2. 保留自己的 `outputs/`、`checkpoints/`、`prompts/`、`logs/`、`.env`、`config.json` 及 `kindle_email.json`。不要用套件的預設設定覆蓋個人設定。
3. 現行 schema 3 的獨立標題／正文／名詞 checkpoint 可繼續使用。舊單一 JSON 檔會保留但不再沿用，重新執行會重新請求翻譯。
4. 只辨識 `0001 - 作品名稱.txt`／`.html`。舊的 `作品名稱 - 1.txt`／`.html` 不會自動改名或刪除，也不算已完成。需要沿用時請先確認章節，再自行改成現行檔名。

## 環境與隱私

- Windows EXE 不需另裝 Python 或 Python 套件。Codex 模式仍需另裝並登入 Codex；自動網頁上傳需已安裝 Chrome 或 Edge。
- Email 寄送目前僅支援個人 Gmail 與 Google 應用程式密碼；需先在 Amazon 核准寄件地址。附件上限 18 MB。
- 發布 ZIP 只包含 EXE、`_internal` 及乾淨的預設 `config.json`；不包含個人設定、作品、自訂 Prompt 或認證資料。EXE 不包含開發者工具頁。
- 請勿分享日常使用的完整程式資料夾，亦勿分享舊瀏覽器設定檔。

## 已知限制與待修問題

本次為既有功能與清理工作的打包，以下先前檢查問題尚未修正：

- Gemini 尚未設定有限的請求逾時；連線卡住時可能長時間等待。
- Gemini 非空白但因輸出長度限制截斷的回覆，可能仍被視為成功；請留意譯文完整性。
- 作者更改作品名稱或使用者改名資料夾後，章節輸出路徑可能與作品記憶位置不一致。
- 作者只改章節標題時，可能因 checkpoint 身分不符而停止。
- 取消翻譯後，名詞分析的部分流程仍可能送出後續請求。
- `config.json` 仍為直接覆寫，寫入中斷可能造成設定損壞。
- 主視窗關閉保護尚未涵蓋 EPUB／寄送背景工作；操作期間請勿關閉整個程式。

自動網頁上傳可能受 Amazon 網站改版、登入或驗證限制影響。Gmail 接受郵件不代表 Kindle 已完成收書。真實寄送與乾淨電腦的端到端測試仍需使用者確認。
