# 電子書單章翻譯

入口：主 GUI → 電子書 → 翻譯。先在作品設定選擇作品，再由 OCR 或 Codex 提取匯出章節原文。

## 操作

1. 下拉選擇已匯出的章節；章節編號可從 000 開始。
2. 電子書翻譯只使用 Codex。切換到翻譯分頁時自動檢查登入並載入模型與推理強度；也可按「更新模型／檢查登入」重試。執行中的工作不會重複連線，不會自動翻譯。
3. 「分析章節」只讀本機資料，不發送翻譯。下方分析結果使用與網文相同的灰底摘要，依內容及視窗寬度自動調整高度，列出字元數、模型與強度、分段字數、可續傳進度與回合數上限；原文框可伸展並使用剩餘空間。修改設定會清除過期結果。分段數 1–20，沿用網文的自然段落分段規則；沒有足夠段落時會要求減少數量。
4. 「翻譯／續傳」會重新讀取目前原文、設定與 Prompt，以目前版本決定可用的 checkpoint；確認回合數後開始。不讀取或更新電子書專有名詞檔案，Codex 對話上下文仍會沿用。
5. 「重新翻譯」清除這份原文、模型、Prompt、分段設定對應的 checkpoint。其他章節與其他設定的進度不受影響。
6. 整章翻譯完成後先合併全部分段，再套用閱讀分行，最後保存 TXT 與 HTML；兩種格式使用同一份分行後正文。只新增換行，不更動文字與標點；原文與 checkpoint 保留原樣。既有檔案不自動重寫。按「開啟 HTML」閱讀；既有譯文須確認覆蓋，不產生 v2 檔名。

取消會等待目前請求完成後停止，已完成分段可續傳，不輸出不完整章節。操作期間不能切換作品或關閉主 GUI；仍可切換分頁檢視。

## 共用與獨立資料

- 與網文共用 `core/shared/translation_controller.py`、`translation_bootstrap.py`、翻譯策略、切塊、checkpoint、名詞記憶、TXT／HTML 格式與章節導航。
- 使用共用「Prompt 模板 → 章節翻譯」，儲存的修改於下次翻譯生效；進行中的翻譯使用啟動時讀取的模板。
- 電子書模型、推理強度及章名處理選項保存在 `runtime/ebook/translation.json`，不覆寫網文選項。舊設定檔仍可讀取，但 Gemini 與專有名詞選項不再使用。
- Codex 顯示帳號額度觀測與作品內的翻譯回合紀錄；帳號額度可能同時受其他任務影響。網文的 Gemini、金鑰與專有名詞功能不變。
- 同作品 Codex 翻譯沿用 `codex_session.json`，與圖片提取的 `codex_extraction_thread.json` 分開。

```text
作品資料夾/
├─ work.json
├─ chapters.json
├─ originals/
│  └─ 000.txt
├─ translations/
│  ├─ 000.txt
│  └─ 000.html
├─ translation-checkpoints/
├─ codex_session.json          # 翻譯對話與待處理回合
├─ codex_extraction_thread.json # 圖片提取對話
└─ codex_usage.jsonl
```

`chapters.json` 的頁碼資料原樣保留，不放進 HTML 正文。若章節沒有獨立 `title`，以「第 000 章」等編號作標題，不額外請模型發明章名。TXT 格式比照網文，包含書名、章名、來源、模型及內文分隔線。

翻譯完成記錄 `translation_source_sha256`、模型、標題與 HTML 檔名。每次載入會核對實際原文內容，原文變更時提示舊譯文可能需要重譯。翻譯途中原文或頁碼資料變更，拒絕寫入輸出；已完成的 checkpoint 保留。

TXT／HTML 先在作品資料夾內暫存並完成產生，再提交及更新索引。一般寫入例外會還原先前輸出；不宣稱跨多檔案操作能抵抗強制斷電。HTML 按章節數字連接既有頁面，章節不連號也可使用。

此版只有單章操作，不含批次、插圖嵌入、EPUB 或翻譯後校訂介面；OCR／Codex 原文校訂不受影響。測試使用合成內容和模擬翻譯，不會上傳私有作品或呼叫付費模型。
